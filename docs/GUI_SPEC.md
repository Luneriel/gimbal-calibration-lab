# 界面与操作

界面使用简体中文和暗色主题，提供“场景搭建 / 模拟数据生成 / 标定验证”三个页面。Ctrl+1、Ctrl+2、Ctrl+3 切页，切换时保留当前配置。

## 场景搭建

左侧对象树、中央三维视图、右侧属性编辑器，底部为 Yaw/Pitch 角度控制。

- 对象树与三维选择联动；传感器挂载变更会更新层级和位姿。
- 左键拖动旋转，中键或 Shift+左键平移，滚轮缩放；支持总览、正视、俯视及坐标系/视锥显示。
- 属性使用 mm 和 °，可配置轴心、轴向、关节零位、传感器安装、G 与 IMU 绝对参考方向。
- 滑块与精确输入遵守关节限位，非法编辑会回滚并提示。
- 项目菜单提供保存、打开、另存为、重命名及恢复场景。加载示例后需自行选择数据输出位置。

## 模拟数据生成

左侧采样参数、右侧相机预览、底部输出和生成控制。

- 默认自动采样 30 组、Yaw ±30°、Pitch ±15°；高级设置包括分布、种子、严格模式和最大尝试次数。
- 手动模式在场景页调姿态后保存；重复姿态不会重复导出。
- 预览显示实际 JPEG、角点检测、姿态和四元数；适应/1:1、缩放、平移及角点叠加仅改变显示。
- 生成使用冻结快照，区分配置、运行、完成、有效不足、取消和失败状态；支持停止。
- 打开实验后按实际文件回放，提供上一帧、下一帧和滑块；失败记录显示原因，独立 3D 回放不影响编辑器。

## 标定验证

依次选择程序预设、图片目录、TXT 目录、输出 YAML，再点击开始。

- “管理预设”配置可执行程序、CMake 目标或 CPP 关联工程及输入/输出约定。
- 执行前展示实际参数、工作目录、样本和输出，确认后才构建或运行。
- 高级设置提供超时、人工输入、重复实验、样本子集、历史实验和原始日志。
- 算法对比保留全部候选及来源；3D 对比使用独立视图；逐帧分析区分输入模型和真值；日志关联所选运行。
- 动态模型、未知输入关系和非法结果显示不适用及原因，不用零误差替代。
- 已有结果拒绝覆盖，当前配置不会改写已经保存的实验。

## 持久化与错误反馈

项目 JSON 使用 Schema 2，兼容旧版 1。加载先验证，写入使用临时文件和原子替换；未保存项目在新建、打开和退出时提示。错误可以通过状态栏和运行日志查看。

坐标和单位见 [COORDINATES.md](COORDINATES.md)，数据及执行接口分别见 [DATASET_FORMAT.md](DATASET_FORMAT.md) 与 [EXPERIMENT_SERVICE.md](EXPERIMENT_SERVICE.md)。
